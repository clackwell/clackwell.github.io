2. What is a Bookmarklet?

A bookmarklet is a regular web browser bookmark that contains a small snippet of JavaScript code instead of a traditional website URL (prefixed with javascript:).

When you click a bookmarklet, your browser executes that code directly in the context of the page you are currently viewing. It does not require installing browser extensions, requires no special permissions, and runs completely locally inside your browser tab.

3. What This Bookmarklet Does

The standard customer account portal on smart.com displays limited order summary cards. This bookmarklet unlocks and organizes the complete vehicle and order information payload:

  1. Automatic ID Detection: Identifies your 10-digit smart order ID directly from the open orders page.
  2. Background Data Fetch: Queries smart's backend BFF API using your active session authentication.
  3. Responsive 8-Tab Overlay: Renders a non-intrusive modal overlay without navigating away from the page (Overview & Pricing, Line Items, Vehicle & Config, Technical Specs, Equipment, Leasing & Partner, Customer & Addresses, and Full JSON).
  4. Dual-Language Mode: A top header selector to toggle between English and German, plus the ability to click any translated label to inspect its original German backend string.
